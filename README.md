# 外贸综合服务平台小程序 - 功能图谱及介绍

## 一、平台概述

外贸综合服务平台是一个连接外贸需求方与服务商的综合性B2B服务平台，采用S2B2C（Supply chain to Business to Consumer）模式，提供从需求发布、服务匹配、订单管理、支付结算到培训教育的全链路服务。平台融合丹纳赫管理体系（VOC、Kaizen、SOP、KPI、PDCA），实现服务质量的持续改进。

## 三、功能模块详细介绍

### 1. 用户与认证模块

#### 1.1 功能概述
提供用户注册、登录、身份认证和角色管理功能，支持微信授权一键登录，实现多角色（需求方、服务商、学员、合作伙伴）的统一管理。

#### 1.2 核心功能
- **微信授权登录**：用户通过微信授权快速登录，获取openid和unionid
- **手机号绑定**：首次登录后绑定手机号，用于接收通知和身份验证
- **角色管理**：用户可申请成为需求方、服务商、学员或合作伙伴，支持多角色身份
- **用户信息管理**：维护用户基本信息、联系方式、资质证明等

#### 1.3 业务规则
- 每位用户拥有唯一用户ID
- 微信openid与用户ID绑定，支持多设备登录
- 角色申请需管理员审核通过后生效
- 用户信息修改后需重新审核（涉及资质信息）

---

### 2. 需求与匹配模块

#### 2.1 功能概述
需求方发布外贸服务需求，系统根据业务类型、目标市场、预算等条件智能匹配推荐合适的服务商，实现供需精准对接。

#### 2.2 核心功能
- **需求发布**：填写业务类型（报关/物流/退税/融资等）、目标市场、预算范围、紧急程度、详细描述
- **智能匹配算法**：
  - 根据业务类型筛选对应服务类型的服务商
  - 根据目标市场筛选地区覆盖范围匹配的服务商
  - 根据服务商评分（高到低）排序
  - 根据服务商接单容量（当前接单数/最大接单数）排序
  - 综合以上因素生成推荐列表
- **服务商列表展示**：展示匹配的服务商信息（名称、评分、服务类型、地区覆盖、接单量）
- **大额单人工分配**：预算≥10万元的需求需管理员人工审核并手动分配

#### 2.3 业务规则
- 需求发布后状态为"待分配"
- 系统自动推送匹配的服务商列表给需求方
- 需求方可主动联系服务商或等待服务商接单
- 大额单需管理员介入，确保服务质量

---

### 3. 订单与交易模块

#### 3.1 功能概述
实现从需求发布到服务完成的完整订单生命周期管理，支持报价单生成、担保交易支付、订单状态流转、双向评价等功能。

#### 3.2 核心功能
- **订单创建**：需求方选择服务商后创建订单
- **报价单生成**：服务商填写服务内容、价格、交付时间，生成报价单
- **报价单确认**：需求方确认报价单，选择支付方式（担保交易）
- **担保交易支付**：通过微信支付JSAPI完成支付，资金先进入平台账户
- **订单状态流转**：
  - 待分配 → 已推送 → 已接单 → 待确认（报价） → 待支付 → 进行中 → 已完成/已取消
- **订单完成确认**：服务商完成服务后点击"确认完成"，需求方确认后平台释放资金
- **双向评价**：订单完成后双方均可评价对方（1-5星评分+文字评价）

#### 3.3 业务规则
- 平台抽佣比例：3-5%
- 支付金额 = 服务费 + 平台抽佣
- 资金流转：需求方支付 → 平台账户 → 服务完成后释放给服务商
- 纠纷时支持退款，根据处理结果确定退款金额
- 评价提交后不可修改，影响用户信用评分

---

### 4. IM即时通讯模块

#### 4.1 功能概述
提供需求方与服务商之间的实时沟通功能，支持文字、图片、语音消息，关键节点自动推送微信服务通知。

#### 4.2 核心功能
- **实时聊天**：支持文字、图片、语音消息发送
- **消息推送**：关键节点（接单、报价、支付、完成）推送微信服务通知
- **聊天记录持久化**：聊天记录保存至云端，支持历史查询
- **在线状态管理**：显示用户在线状态，支持离线消息

#### 4.3 业务规则
- 消息通过WebSocket实现实时通信
- 离线消息在用户上线后推送
- 敏感词过滤，防止违规内容
- 聊天记录保留至少1年

---

### 5. 培训平台模块

#### 5.1 功能概述
提供外贸培训课程发布、学习、测验、证书生成等功能，服务商可申请成为讲师，用户完成课程学习后可获得学习证书。

#### 5.2 核心功能
- **讲师申请**：服务商提交讲师申请（姓名、专业领域、从业经验、资质证明）
- **课程发布**：讲师发布课程（课程名称、简介、大纲、章节、图文/视频内容、测验）
- **课程审核**：管理员审核课程内容，审核通过后上线
- **课程学习**：学员按章节学习图文和视频内容，学习进度自动记录
- **课程测验**：学完课程后参加测验，通过测验生成学习证书
- **学习进度记录**：记录学员学习进度，支持断点续学

#### 5.3 业务规则
- 讲师需管理员审核通过后才能发布课程
- 课程需管理员审核通过后才能上线
- 课程收益分成：讲师70%，平台30%
- 收益结算：每月1日自动结算上月收益
- 学员完成课程并通过测验后生成电子证书

### 6. 丹纳赫管理体系模块

#### 6.1 功能概述
融合丹纳赫管理理念，提供VOC客户之声、Kaizen改善看板、SOP标准作业库、KPI绩效仪表盘、PDCA追踪等功能，实现服务质量的持续改进。

#### 6.2 核心功能

**6.2.1 VOC客户之声**
- 用户对服务商进行分维度评分（及时性/专业度/沟通/结果，1-5星）
- 系统自动汇总VOC反馈，生成服务商画像
- 服务商可查看自己的VOC反馈和画像

**6.2.2 Kaizen改善看板**
- 用户提交Kaizen改善建议（问题描述、改善措施、预期效果）
- 管理员跟踪处理进度（提交→分析→实施→验证→关闭）
- 可视化看板展示所有改善项状态
- 改善项状态更新时通知提交人

**6.2.3 SOP标准作业库**
- 管理员发布SOP模板（名称、服务类型、标准操作流程、注意事项、参考文档）
- 服务商和用户可查看SOP模板，参考执行
- SOP模板按服务类型分类展示

**6.2.4 KPI绩效仪表盘**
- KPI指标：按时完成率、客户满意度、改善项数、复购率、NPS净推荐值
- 系统自动计算服务商KPI绩效
- 管理员可查看平台整体KPI总览
- 排行榜展示Top 20服务商

**6.2.5 PDCA追踪**
- 每个Kaizen改善项按PDCA四阶段追踪：
  - Plan（计划）：改善措施
  - Do（执行）：实施记录
  - Check（检查）：验证结果
  - Act（行动）：标准化/推广
- 可视化展示PDCA进度

#### 6.3 业务规则
- VOC反馈提交后不可修改
- Kaizen改善项状态更新需管理员操作
- KPI数据每日凌晨0点更新
- PDCA各阶段进度由管理员更新

### 7. 合作伙伴模块

#### 7.1 功能概述
外综服务团队可申请入驻平台成为合作伙伴，承接订单服务，获得佣金分成。支持个人合作和团队合作两种类型。

#### 7.2 核心功能
- **合作伙伴申请**：填写姓名/团队名、服务类型（多选）、资质证明、联系方式、简介
- **申请审核**：管理员人工审核，审核通过后成为合作伙伴
- **合作伙伴管理**：管理员可查看合作伙伴详情、禁用/启用合作伙伴
- **业绩管理**：展示合作伙伴业绩数据（订单数量、完成订单数、成交金额、收益金额）
- **佣金结算**：合作伙伴获得订单服务费的一定比例作为佣金

#### 7.3 业务规则
- 合作伙伴申请需管理员审核
- 审核拒绝时需填写拒绝理由
- 合作伙伴可承接订单，完成后体现业绩和收益
- 佣金分成比例由平台设定

### 8. 客服系统模块

#### 8.1 功能概述
提供人工客服和AI智能客服双通道服务，工作时间提供人工客服，非工作时间自动切换为AI智能客服（文心大模型），客服工作可外包给合作伙伴。

#### 8.2 核心功能
- **人工客服**：工作时间（9:00-18:00）提供人工客服在线服务
- **AI智能客服**：非工作时间自动切换为文心大模型AI客服
- **客服分配**：管理员可手动分配咨询给合作伙伴处理
- **咨询记录管理**：持久化保存咨询记录，支持历史查询

#### 8.3 业务规则
- 工作时间内优先展示人工客服入口
- 非工作时间自动切换为AI智能客服
- 客服咨询可分配给合作伙伴回复
- 合作伙伴回复后用户收到通知
- 消息记录持久化保存

### 10. 跨境货盘模块

#### 10.1 功能概述
提供跨境货盘资源库，展示可用货盘信息，仅完成培训平台课程的学员可申请使用货盘，实现培训与供应链的联动。

#### 10.2 核心功能
- **货盘发布**：填写货品类型、数量、原产地、价格区间、有效期、联系方式
- **货盘展示**：展示货盘列表，支持筛选（在售/已下架/已售完）
- **货盘申请**：学员选择货盘，填写采购意向（数量、目标市场、联系方式）
- **货盘审核**：管理员审核申请，验证申请人是否已报名课程
- **货盘状态管理**：管理员更新货盘状态（在售/已下架/已售完）

#### 10.3 业务规则
- 仅完成培训平台课程（已报名）的学员才能申请货盘
- 管理员审核时验证申请人学员身份
- 审核通过后，货盘方联系申请人
- 货盘来源：平台合作供应商提供

### 11. 会员与积分模块

#### 11.1 功能概述
提供多层级会员体系和积分系统，通过积分激励和会员权益促进用户活跃度和交易转化。

#### 11.2 核心功能

**11.2.1 会员等级**
- **免费层**：可发布需求，查看匹配服务商
- **付费层**：按成交抽佣3-5%
- **订阅层**：年度会员费，享受优先匹配和专属顾问服务
- **企业层**：定制咨询服务，单独报价

**11.2.2 积分系统**
- **积分获取**：
  - 完成交易：每笔订单获得订单金额1%的积分
  - 邀请用户：每邀请1位新用户获得100积分
  - 发布需求：每发布1条需求获得10积分
- **积分使用**：100积分可抵扣1元服务费
- **积分规则**：积分不可提现，仅用于抵扣

**11.2.3 首单优惠**
- 新用户首单平台服务费减免50%
- 仅限首次成交订单
- 与积分抵扣可叠加使用

**11.2.4 邀请裂变**
- 每位用户拥有唯一邀请码
- 新用户通过邀请码注册，邀请人获得积分奖励
- 邀请人可获得被邀请人首单佣金减免10%
- 分享海报包含用户专属二维码

#### 11.3 业务规则
- 会员等级由管理员设定权益
- 积分自动计算并发放
- 首单优惠自动识别并应用
- 邀请关系永久绑定

## 六、技术架构

### 6.1 前端技术栈
- **框架**：uni-app（Vue3）
- **UI组件库**：uView UI / uni-ui
- **状态管理**：Pinia
- **HTTP请求**：uni.request封装
- **WebSocket**：uni.connectSocket（IM通讯）

### 6.2 后端技术栈
- **云函数**：uniCloud云函数（Node.js）
- **数据库**：MongoDB（云数据库）
- **文件存储**：uniCloud云存储
- **消息推送**：微信模板消息（Edge Function）
- **AI客服**：文心大模型（wenxin_assistant Edge Function）
- **物流查询**：快递查询API（kdi-query Edge Function）

### 6.3 管理后台技术栈
- **框架**：Vue3 + Element Plus
- **状态管理**：Pinia
- **HTTP请求**：Axios
- **图表库**：ECharts

### 6.4 支付集成
- **支付方式**：微信支付JSAPI
- **支付流程**：担保交易（资金先进入平台账户，服务完成后释放）
- **抽佣比例**：3-5%

### 6.5 AI辅助开发工具
- **代码生成**：Trae AI / Cursor / Copilot（自动生成CRUD页面、接口代码、数据模型）
- **代码审查**：AI Code Review（自动发现代码问题，减少返工）
- **测试用例**：AI Test Generator（自动生成单元测试和集成测试）
- **文档生成**：AI Doc Generator（自动生成API文档、数据库设计文档）
- **UI组件**：AI UI Generator（根据设计稿生成前端组件代码）
- **数据库设计**：AI Schema Designer（自动生成数据库表结构和ER图）
